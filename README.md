# Mash Restoration Panel Beaters

Responsive static website for Mash Restoration Panel Beaters, Belmont, Bulawayo.

## Pages
- `index.html` — homepage, services, restoration gallery, quote enquiry, contact details and restoration guide.
- `hilux-legend45.html` — dedicated Toyota Hilux Legend 45 restoration story.
- `hilux-agx7577.html` — dedicated silver Toyota Hilux Revo (registration AGX 7577) story.
- `hilux-single-cab.html` — dedicated Toyota Hilux single-cab story.
- `project.html` — legacy redirect to the Legend 45 story.

## Stack
Semantic HTML, responsive CSS and vanilla JavaScript. No build step or framework required.

## Functionality
- Responsive navigation and reduced-motion support.
- Quote form prepares an enquiry in WhatsApp; the site does not store form data.
- “Ask Mash” is a guided FAQ assistant, not a live generative AI service. A real AI agent requires a secured server-side model connection and provider credentials.
- Phone, email, WhatsApp and directions links are included.

## Media note
The current homepage hero uses temporary workshop footage. The supplied Mash restoration photographs are not yet stored in this repository's public `assets/` directory, so the case-study pages currently use branded image panels rather than pretending stock photos are Mash project photographs. The supplied originals should be added to the repository's `assets/` directory before the gallery is considered media-complete.

## Deploy
Vercel project: `mash-restoration-panel-beaters`. Static site, no build command, root output.
