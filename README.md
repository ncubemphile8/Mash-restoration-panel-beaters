# Mash Restoration Panel Beaters

Responsive static website for Mash Restoration Panel Beaters, Belmont, Bulawayo.

## Pages
- `index.html` — homepage, services, featured work, quote enquiry, contact details and guided restoration assistant.
- `project.html` — dedicated Toyota Hilux Legend 45 restoration story.

## Stack
Semantic HTML, responsive CSS and vanilla JavaScript. No build step or framework required.

## Run locally
Open `index.html` in a browser, or run `python -m http.server 8000`.

## Functionality
- Responsive mobile navigation and reduced-motion support.
- Quote form prepares an enquiry in WhatsApp; the site does not store form data.
- “Ask Mash” is currently a guided FAQ assistant, not a live generative AI service. A real AI assistant needs a secured server-side model connection and provider credentials.
- Phone, email, WhatsApp and directions links are included.

## Media and project accuracy
- The homepage hero currently uses temporary stock workshop footage from Pexels. Replace it with Mash-owned approved footage for the final brand version.

Replace these with the original supplied before/during/after photographs before public launch.
